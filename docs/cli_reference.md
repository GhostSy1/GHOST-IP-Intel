# GHOST-IP-Intel - CLI Reference Guide

---

## Command Line Options

```bash
python3 main.py --help
```

| Argument | Description | Required | Default |
|---|---|---|---|
| `--target` | Target asset IP, URL, or scope file | No | Interactive prompt |
| `--json` | Output JSON report path | No | `report.json` |
| `--csv` | Output CSV summary path | No | `report.csv` |
